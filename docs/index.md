# AO Brief

A readable AO development brief, backed by public GitHub receipts.

The aim is simple: make public AO, HyperBEAM, Arweave, and permaweb development easier to understand without making readers live inside GitHub.

## Archive

Published briefs are saved in [the archive](briefs/index.md).

## Mailing List

Set a `MAILING_LIST_URL` GitHub Actions variable to point readers to your signup page. When that variable is set, each email includes a simple "Join the list" link.

Good options for the signup page are Buttondown, beehiiv, Loops, ConvertKit, or a small custom form that writes to a SendGrid contact list without exposing the SendGrid API key in the browser.
