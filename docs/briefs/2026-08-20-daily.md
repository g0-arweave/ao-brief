### Quick read:
Today’s HyperBEAM work is small, but useful in the places where builders and node operators feel bugs first: links and storage behavior.

PR #1091 normalizes gateway links in `hb_client_gateway.erl`. In plain terms, that should make gateway-style links more consistent before the node uses them. That helps reduce small link-shape issues that can break fetching, sharing, or client behavior.

That is a narrow fix, but it points at a practical goal: make storage handling fail less often on edge cases or missing options.
