### Quick read:

The clearest AO-facing work was on payment-backed bundler setup. The `lapee-p4-bootstrap-device` update adds dynamic fallback ledgers and top-up route switching, so a node can publish the payment routes it supports and clients can choose one instead of guessing or hardcoding IDs.

That is useful for operators running paid or recharge-backed bundlers: it gives them a cleaner way to support more than one payment path, and it should reduce brittle client setup around top-ups. This follows the recent work on paid-only bundler profiles, recharging ledgers, grace fixes, pinned versions, and ledger fallback handling.

There was also a new `andee-apk-configurator` repo import and docs pass. The practical read: AndEE APK configuration is being turned into a visible web/config tool, with a documented path and a new “source mode.” That is early, but it points toward easier setup and clearer inspection for people packaging or configuring node-like apps.
